# Codex 디자인 하네스 목적

## 목적

나는 매번 달라지는 대상 서비스·경쟁사 레퍼런스·화면 설계 정보를 바탕으로 레퍼런스 분석, 화면 설계, 디자인 제작을 순서대로 진행하고 각 단계 경계의 게이트를 통과시켜, 내부 협의로 컨셉을 확정한 390×844 키스크린 2~3개가 토큰·컴포넌트 가이드 위반 없이 검토된 화면 디자인을 완성한다. [D01-D03]

## 반복마다 달라지는 입력

- 대상 서비스 [D01]
- 경쟁사 레퍼런스 [D01]
- 화면 설계 정보 [D01]

## 직접 사용자

- 본인 [D02]

## 완료 기준

- 컨셉은 내부 협의로 확정한다. [D03]
- UI 키스크린은 390×844 크기로 2~3개 제작한다. [D03, D12]
- 완성 화면은 디자인 토큰·컴포넌트 가이드 위반 없이 검토를 통과한다. [D03, D15]

## 단계 경계 게이트

1. 레퍼런스 검색·분석 후 화면 설계로 넘어가기 전 [D05]
2. 화면 설계 후 디자인 제작으로 넘어가기 전 [D05]
