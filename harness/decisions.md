# 기본값과 결정 출처

이 문서는 하네스에서 쓰는 기본값이 어디서 왔는지 구분한다. `사용자 기록`은 대화에서 직접 정한 내용, `문서 근거`는 기존 프로젝트 문서에서 온 내용, `제안 기본값`은 기존 근거가 없어 인터뷰 중 제안하고 사용자가 승인한 운영 선택이다. 제안 기본값을 PRD나 사용자 원래 방식에서 나온 규칙처럼 표현하지 않는다. [D22]

## 사용 규칙

- 문서 근거가 있는 기준에는 위 ID와 구체 출처를 함께 적는다.
- 사용자 답변으로 정한 기준은 발언 또는 `docs/story-service.md`·`docs/story-work.md` 위치를 적는다.
- 출처가 없는 운영 선택은 `제안 기본값`으로 표시한다. 사용자가 승인했어도 그 출처 유형은 바꾸지 않는다.
- 이후 기본값을 추가할 때는 이 표에 새 ID, 출처 유형, 구체 출처와 한계를 먼저 기록한다.
- 모든 하네스 문서의 기본값에는 이 표의 결정 ID를 붙인다. [D22]
- Codex 실행 형식은 OpenAI 공식 [Subagents 문서](https://developers.openai.com/codex/multi-agent)와 [Hooks 문서](https://learn.chatgpt.com/docs/hooks)를 기준으로 한다. [D27, D28]
